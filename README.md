# Ping-Pong на Pygame

Простая реализация классической игры «Пинг‑понг» на Python с использованием библиотеки Pygame. Два игрока управляют ракетками (левый — W/S, правый — стрелки вверх/вниз), отбивают мяч и стараются не дать ему уйти за пределы поля. Игра завершается, когда мяч уходит за левую или правую границу, и выводится победитель.

## Особенности

- Управление двумя ракетками с клавиатуры.
- Автоматическое отражение мяча от верхней и нижней границ.
- Отскок мяча при столкновении с ракетками.
- Экран завершения с надписью о победителе.
- Использование спрайтов (ракетка и мяч загружаются из файлов).
- Фиксированная частота кадров (60 FPS).

## Требования

- Python 3.8+
- Библиотека `pygame`
